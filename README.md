## Что это простыми словами

ChatGPT Remote Hands — экспериментальный проект, который должен позволить ChatGPT отправлять разрешённые команды на твой собственный Android-телефон и получать результат.

Например, в будущем ты сможешь попросить ChatGPT выполнить поддерживаемую операцию на телефоне, а не копировать команды вручную в Termux.

**Это не удалённый рабочий стол и не полный контроль над телефоном.** Bridge выполняет только явно разрешённые операции. Произвольное выполнение команд оболочки не является целью проекта.

## Как это будет работать

1. На своём Android ты устанавливаешь Termux и личный Bridge.
2. Создаёшь собственный приватный репозиторий GitHub для обмена командами и результатами.
3. GitHub Actions проверяет запрос и передаёт его через защищённый туннель на твой телефон.
4. Bridge проверяет запрос, выполняет только разрешённую операцию и возвращает результат.
5. ChatGPT получает результат через канал интеграции, который поддерживает запись и чтение нужных данных.

У каждого пользователя будут собственные телефон, приватный репозиторий, ключи и туннель. Общего сервера проекта, через который проходят данные всех пользователей, нет.

## Для кого этот проект

Проект создаётся прежде всего для пользователей **ChatGPT**, которые хотят связать помощника со своим Android-устройством.

Есть важное условие: используемый способ интеграции с ChatGPT должен действительно уметь записывать запросы в приватный репозиторий и читать результаты. Сам по себе GitHub connector в ChatGPT может иметь только права чтения. Наличие такого подключения ещё не означает, что оно сможет управлять Bridge.

## Готово ли это к установке?

**Пока нет.** Мы не хотим заставлять новичка разбираться в исходниках и вручную собирать систему из десятков компонентов.

Сейчас в проекте есть:
- локальный Bridge runtime для Termux;
- проверка GitHub OIDC-токенов и защита от повторного выполнения запросов;
- ограниченный список встроенных операций;
- шаблон приватного operational-репозитория и GitHub Actions workflow;
- менеджер SSH reverse tunnel через tunnl.gg;
- первый установочный сценарий для Termux ARM64;
- автоматические тесты проекта.

Что ещё необходимо до публичного запуска:
- проверить установку с нуля на чистом Android/Termux;
- пройти полный end-to-end тест от запроса до результата на телефоне;
- проверить восстановление после обрыва сети и перезапуска;
- подготовить простую пошаговую установку для человека без опыта работы с GitHub и Termux;
- подтвердить реальный write-capable способ связи ChatGPT с приватным репозиторием.

**Хочешь установить проект?** Открой [пошаговую инструкцию для новичка](docs/GETTING_STARTED.md). Наша цель — одна команда в Termux, которая сама установит и настроит все компоненты. Пока установщик проходит проверку, запускать его не нужно.

Также доступен отдельный файл: [скачать промпт-инструкцию для ChatGPT (.md)](CHATGPT_PROMPT_RU.md?raw=1). Его можно добавить в инструкции проекта ChatGPT или загрузить в чат.

## Безопасность и приватность

- У каждого пользователя отдельная установка и отдельный приватный GitHub-репозиторий.
- Приватные SSH-ключи и локальные секреты создаются на устройстве и не публикуются.
- В публичном репозитории находятся только исходники, документация, тесты и чистые шаблоны.
- Bridge принимает только проверенные запросы и разрешённые операции.
- Проект не должен получать скрытый или неограниченный доступ к телефону.

Не публикуй в Issues, Discussions или других публичных местах токены, пароли, приватные ключи, конфигурации и личные адреса туннелей. Подробности — в [SECURITY.md](SECURITY.md).

## Ограничения, о которых нужно знать

- Android может останавливать фоновые процессы; круглосуточная работа не гарантируется.
- Бесплатный режим tunnl.gg имеет ограничения по времени сессии, простоям и объёму трафика.
- HTTP-ответ о принятии запроса ещё не означает, что команда выполнена.
- Успешный запуск GitHub Actions сам по себе не подтверждает выполнение на телефоне — нужно проверить результат.
- Это независимый open-source проект, **не официальный продукт OpenAI и не проект, одобренный OpenAI**.
