# Tunnel / SSH

## Назначение

Туннель обеспечивает входящую доставку событий к локальному listener на Android без прямого открытия listener в публичный интернет.

## Требования к провайдеру

- Поддержка SSH reverse forwarding или документированного эквивалента.
- Проверяемый host key fingerprint.
- Понятная процедура регистрации public key.
- Возможность обнаружить смену endpoint/URL.
- Прозрачные лимиты, idle timeout и условия бесплатного плана.
- Допустимость использования для выбранного сценария.

## Безопасная настройка

- Генерировать уникальную SSH key pair локально.
- Private key никогда не покидает устройство.
- Передавать провайдеру только public key.
- Хранить known_hosts и проверять host key; не отключать строгую проверку.
- Ограничить listener loopback-интерфейсом.
- Сохранять текущий URL только в приватной конфигурации пользователя.
- При ротации URL обновлять private operational repository безопасно и последовательно.

## Ограничения

Бесплатный внешний туннель может иметь лимиты, менять URL, прекращать idle sessions или быть недоступен. Android может завершать фоновые процессы. Не обещать постоянный URL или uptime.
