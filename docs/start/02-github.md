# Шаг 2. Подготовить аккаунт GitHub

GitHub будет хранить личную очередь запросов и результатов. Для каждого пользователя создаётся отдельный **приватный** репозиторий. Он не будет виден другим пользователям.

## 1. Открой GitHub

[Открыть GitHub →](https://github.com/)

Если аккаунта ещё нет, нажми **Sign up** и пройди регистрацию. Если аккаунт уже есть — войди в него.

## 2. Проверь, что можешь открыть свои репозитории

[Открыть список своих репозиториев →](https://github.com/)

Ничего вручную создавать пока не нужно. Установщик должен будет создать отдельный приватный репозиторий автоматически и проверить, что он действительно принадлежит тебе и имеет приватную видимость.

## 3. Что будет при установке

На этапе установки Termux откроет официальный процесс авторизации GitHub CLI. Он покажет ссылку и код подтверждения. Ты сам откроешь страницу GitHub, введёшь код и разрешишь доступ. Пароль, код или токен не нужно отправлять в ChatGPT.

**Не создавай Personal Access Token вручную и не публикуй данные авторизации.**
