# Шаг 6. Проверить работу

<em>Полный сквозной тест пока не подтверждён. Эта страница станет пошаговым тестом после проверки установки.</em>

Установка считается успешной не тогда, когда команда принята GitHub или workflow завершился без ошибки, а когда Bridge на телефоне действительно выполнил разрешённую операцию и вернул результат.

## Что будет проверяться

1. Локальный Bridge отвечает на проверку состояния.
2. Туннель доступен снаружи.
3. GitHub Actions может доставить тестовый запрос.
4. Bridge проверяет подлинность запроса и его разрешённость.
5. На телефоне выполняется безопасная тестовая операция.
6. Результат возвращается в приватный репозиторий и доступен ChatGPT.

## Как выглядит настоящий успех

Ты увидишь подтверждение именно результата выполнения, а не только сообщение «запрос отправлен» или «workflow завершён».

Если тест не пройдёт, инструкция покажет, где посмотреть безопасную диагностику. Логи и конфигурации перед публикацией нужно проверять на отсутствие секретов.
