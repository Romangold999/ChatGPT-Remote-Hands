# Шаг 3. Установить личный Bridge

<em>Этот шаг пока не открыт для выполнения.</em>

Установщик ещё должен пройти проверку на чистом Android/Termux. До этого момента не запускай команды из исходников и не пытайся собирать систему вручную.

## Что будет происходить после открытия установки

1. Ты откроешь Termux.
2. Вставишь одну проверенную команду установки.
3. Установщик подготовит необходимые пакеты.
4. Ты подтвердишь вход в GitHub через официальную страницу авторизации.
5. Установщик создаст твой отдельный приватный репозиторий и настроит локальный Bridge.
6. В конце он покажет, что удалось настроить, а что требует внимания.

Установщик не должен создавать общий аккаунт или отправлять приватные ключи в публичный репозиторий.

## Что появится на этой странице перед релизом

- точная команда установки с кнопкой копирования;
- пояснение, куда её вставить в Termux;
- примеры экранов авторизации;
- ожидаемый текст успешного завершения;
- способ безопасно повторить установку, если процесс прервался.
