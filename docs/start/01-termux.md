# Шаг 1. Подготовить Android и установить Termux

На этом этапе нужно только установить приложение Termux из надёжного источника. Сам Bridge пока не устанавливаем.

## 1. Открой страницу Termux

[Открыть официальный репозиторий Termux и страницу релизов →](https://github.com/termux/termux-app/releases)

Выбери актуальную стабильную сборку приложения Termux для Android. Не скачивай APK со случайных сайтов.

## 2. Установи приложение

1. Скачай APK из официального репозитория.
2. Открой скачанный файл.
3. Если Android спросит разрешение на установку из этого источника, разреши его для браузера или файлового менеджера, которым ты открыл APK.
4. Заверши установку и запусти Termux.

## 3. Как понять, что всё готово

Открылось окно Termux с командной строкой. На этом шаге ничего вводить не нужно.

**Важно:** если позже понадобятся дополнительные приложения Termux, например Termux:API или Termux:Boot, их нужно будет устанавливать из того же источника сборки/подписи, что и сам Termux. Termux:Boot не будет включаться автоматически.
