# Шаг 5. Подключить ChatGPT

<em>Этот шаг пока не готов к выполнению: write-capable способ интеграции ещё должен быть подтверждён.</em>

Чтобы связка работала в обе стороны, канал интеграции должен уметь:

- записывать новый запрос в твой приватный репозиторий;
- запускать предусмотренный workflow;
- читать итоговый результат и передавать его ChatGPT.

Одного доступа на чтение недостаточно.

## Важное уточнение про GitHub connector

Подключённый в ChatGPT GitHub connector может иметь только права чтения. Поэтому нельзя считать, что после подключения GitHub всё автоматически заработает. Перед публикацией простой инструкции мы проверим реальный канал записи и чтения и покажем точные действия для него.

[Открыть ChatGPT →](https://chatgpt.com/)

Не выдавай интеграции больше прав, чем требуется, и не вставляй личные токены или приватные ключи в обычный чат.
