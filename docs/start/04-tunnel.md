# Шаг 4. Подключить защищённый туннель

<em>Этот шаг будет выполняться установщиком; пока не запускай его вручную.</em>

Туннель нужен, чтобы GitHub Actions мог доставить разрешённый запрос снаружи до Bridge, который работает на твоём телефоне.

## Что такое tunnl.gg

[Открыть официальную документацию tunnl.gg →](https://tunnl.gg/docs)

Проект использует SSH reverse tunnel. Для стабильного адреса сервис требует зарегистрировать отдельный SSH-ключ.

## Что ты увидишь при установке

1. Termux создаст отдельный ключ именно для этого Bridge.
2. В окне Termux появится ссылка для регистрации ключа.
3. Ты откроешь её в браузере и завершишь регистрацию на сайте tunnl.gg.
4. Вернёшься в Termux и подтвердишь, что регистрация завершена.
5. Установщик проверит туннель и сохранит его адрес в приватных настройках.

Приватный SSH-ключ останется на телефоне. Не отправляй его никому и не добавляй в GitHub.

## Ограничения бесплатного режима

У бесплатного tunnl.gg есть ограничения по числу туннелей, объёму трафика, простою и длительности одной сессии. Android также может остановить Termux в фоне. Поэтому непрерывная работа 24/7 не обещается.
