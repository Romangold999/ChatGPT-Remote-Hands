# Установка ChatGPT Remote Hands

> **Статус: установщик пока проходит проверку.** Не запускай команду ниже, пока здесь не появится отметка «Проверено». Мы должны сначала подтвердить установку с нуля на чистом Termux и полный тест связи.

Наша цель — чтобы тебе не пришлось вручную устанавливать Python, Git, SSH, GitHub CLI и другие компоненты. Всё это должен сделать один установщик.

## Шаг 1. Установи Termux

[Открыть официальные релизы Termux →](https://github.com/termux/termux-app/releases)

1. Скачай актуальный стабильный APK из официального репозитория.
2. Установи и открой Termux.
3. Дождись первого запуска. Больше ничего вручную устанавливать не нужно.

Важно: не смешивай Termux и его дополнительные приложения из разных источников — у них должны совпадать подписи. Для базовой установки ChatGPT Remote Hands дополнительные приложения Termux не требуются. [Подробнее об источниках и подписях →](https://github.com/termux/termux-app#installation)

## Шаг 2. Подготовь GitHub

[Открыть GitHub →](https://github.com/)

Войди в свой аккаунт или зарегистрируйся. Создавать репозиторий вручную не нужно: установщик должен создать отдельный приватный репозиторий автоматически.

## Шаг 3. Запусти одну команду в Termux

<badge color="warning">Пока не запускать — идёт проверка установщика</badge>

После проверки здесь появится одна команда. Её нужно будет скопировать целиком, вставить в Termux и нажать Enter.

Установщик самостоятельно:
- обновит список пакетов и установит нужные системные компоненты;
- скачает ChatGPT Remote Hands и подготовит изолированное окружение;
- проведёт авторизацию GitHub через официальный браузерный/device flow;
- создаст твой личный приватный репозиторий и настроит GitHub Actions;
- создаст отдельный SSH-ключ на телефоне;
- поможет зарегистрировать ключ tunnl.gg и настроит туннель;
- запустит Bridge и проверит локальное состояние.

**От тебя потребуются только подтверждения.** Например, когда Termux покажет ссылку и одноразовый код GitHub, открой страницу GitHub, введи код и подтверди доступ. Когда появится ссылка tunnl.gg, открой её и заверши регистрацию ключа. Затем вернись в Termux — установщик продолжит работу.

Никакие пароли, одноразовые коды, токены или приватные ключи не нужно отправлять в ChatGPT или публиковать в GitHub.

## Шаг 4. Убедись, что установка завершилась

В конце установщик должен показать:
- адрес твоего приватного репозитория;
- состояние локального Bridge;
- состояние туннеля;
- результат проверки соединения;
- следующую инструкцию для подключения ChatGPT.

Сообщение «запрос принят» или зелёная галочка GitHub Actions сами по себе не доказывают, что телефон выполнил операцию. Финальная проверка должна подтвердить именно результат на устройстве.

## Что важно знать

- Проект рассчитан на Android ARM64 и Termux.
- У каждого пользователя свои телефон, приватный репозиторий, SSH-ключ и туннель.
- Bridge должен выполнять только явно разрешённые операции, а не произвольные команды оболочки.
- Android может останавливать фоновые процессы; работа 24/7 не гарантируется.
- Бесплатный tunnl.gg имеет ограничения по трафику, простою и длительности сессии.
- Для полноценной связи ChatGPT нужен канал, способный записывать запросы и читать результаты. GitHub connector может быть доступен только для чтения — это нужно учитывать отдельно.
- Это независимый open-source проект, не официальный продукт OpenAI и не одобрен OpenAI.
