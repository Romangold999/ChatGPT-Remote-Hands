# Начало работы — ChatGPT Remote Hands

> **Статус: подготовительная инструкция. Установка пока закрыта для новичков.**  
> Мы ещё не подтвердили полный путь на чистом Android: от установки Termux до получения ChatGPT результата с телефона. Поэтому пока не запускай команды установки и не создавай рабочие ключи по этой инструкции. Когда проверка завершится, здесь появятся точные команды и снимки ожидаемых экранов.

## Что понадобится

- Android ARM64 и приложение Termux.
- Аккаунт GitHub.
- Доступ к сети для GitHub и tunnl.gg.
- ChatGPT и отдельный канал интеграции, который сможет **записывать запросы и читать результаты**. Наличие GitHub connector само по себе этого не гарантирует: у него могут быть только права чтения.

## Что важно знать заранее

- Это независимый open-source проект, не официальный продукт OpenAI и не одобрен OpenAI.
- У каждого пользователя будет свой приватный репозиторий, собственные ключи и собственный туннель.
- Bridge не предназначен для скрытого или неограниченного управления телефоном: он должен выполнять только разрешённые операции.
- Android может останавливать фоновые процессы. Круглосуточная работа не гарантируется.
- Не отправляй пароли, токены, приватные ключи и адрес личного туннеля в чат или публичные Issues.

## Текущий статус

Пока подтверждены автоматические тесты проекта, но не полный тест установки с нуля на чистом телефоне. Мы откроем пошаговую установку только после проверки всех этапов и исправления найденных проблем.

**Если ты пришёл сюда впервые — начни с шага 1, чтобы ознакомиться с требованиями. Не переходи к установке Bridge, пока на этой странице явно не появится статус «Установка проверена».**
