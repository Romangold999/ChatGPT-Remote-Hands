# Установка ChatGPT Remote Hands

> **Статус: установщик пока проходит проверку.** Команда ниже показана для понимания будущего способа установки, но пока не запускай её. Перед публичным запуском нужно подтвердить установку с нуля на чистом Termux и полный тест связи.

Наша цель — чтобы новичку не пришлось вручную устанавливать Python, Git, SSH, GitHub CLI и другие компоненты. Всё это должен сделать один установщик.

## Шаг 0. Сначала подключи промпт в ChatGPT

Это первый шаг — ещё до установки Termux.

1. Скачай [главный промпт ChatGPT Remote Hands (.md)](https://raw.githubusercontent.com/Romangold999/ChatGPT-Remote-Hands/main/CHATGPT_PROMPT_RU.md).
2. Загрузи файл в новый чат ChatGPT или добавь его в инструкции проекта ChatGPT.
3. Напиши: **«Проведи меня через установку ChatGPT Remote Hands от начала до конца. Веди меня по одному шагу и проверяй результат каждого этапа».**

Промпт содержит полную навигацию по репозиторию, ссылки на Termux, GitHub и tunnl.gg, процедуру установки, ограничения, правила безопасности и техническую карту проекта.

Важно: сам промпт не подключает GitHub и не даёт ChatGPT доступ к телефону. Он помогает ChatGPT правильно провести тебя через установку и дальнейшую работу.

## Шаг 1. Установи Termux

- [Открыть официальные релизы Termux](https://github.com/termux/termux-app/releases)
- [Руководство по установке и источникам](https://github.com/termux/termux-app#installation)
- [Termux в F-Droid](https://f-droid.org/packages/com.termux/)

1. Скачай актуальный стабильный APK из официального источника.
2. Установи и открой Termux.
3. Дождись первого запуска и появления командной строки.
4. Вернись в ChatGPT к помощнику с подключённым промптом.

Не смешивай Termux и дополнительные приложения из разных источников подписи. Для базовой установки дополнительные приложения Termux не требуются. Termux:API и Termux:Boot необязательны; Boot не включается без отдельного согласия.

## Шаг 2. Подготовь GitHub

- [Открыть GitHub](https://github.com/)
- [Создать аккаунт](https://github.com/signup)
- [Войти в существующий аккаунт](https://github.com/login)

Если ты уже вошёл в GitHub, повторно авторизоваться не нужно. Если нет — войди. Создавать приватный operational repository вручную не нужно: это должен сделать установщик.

## Шаг 3. Одна команда в Termux — пока не запускать

<badge color="warning">Экспериментальная команда — не запускать до clean install и e2e проверки</badge>

После проверки команда будет отображаться прямо здесь. Её можно будет скопировать целиком, вставить в Termux и нажать Enter.

Предварительная команда:

    tmp="$(mktemp)" && curl -fsSL "https://raw.githubusercontent.com/Romangold999/ChatGPT-Remote-Hands/main/scripts/install.sh" -o "$tmp" && bash "$tmp"; rc=$?; [ -z "$tmp" ] || rm -f "$tmp"; exit "$rc"

Она скачивает установочный скрипт во временный файл, запускает его в интерактивной сессии и удаляет временный файл после завершения.

Установщик должен самостоятельно:
- установить системные зависимости;
- скачать и подготовить Bridge;
- провести GitHub browser/device authorization, если вход ещё не выполнен;
- создать отдельный приватный репозиторий и настроить workflow;
- создать отдельный SSH-ключ на телефоне;
- помочь зарегистрировать ключ tunnl.gg;
- запустить Bridge и туннель;
- проверить локальное и внешнее соединение.

От пользователя потребуются только неизбежные подтверждения в браузере. Например, открыть ссылку GitHub, ввести одноразовый код и подтвердить доступ; затем открыть ссылку tunnl.gg и завершить регистрацию SSH-ключа. Не отправляй коды, токены, пароли или private keys в ChatGPT.

## Шаг 4. Проверка результата

В конце установки нужно подтвердить:
- адрес личного приватного репозитория;
- состояние локального Bridge;
- состояние туннеля;
- ответ внешнего health check;
- выполнение тестовой команды на телефоне;
- публикацию результата с правильными ID и sequence в mailbox.

Сообщение «запрос принят» или зелёная галочка GitHub Actions сами по себе не доказывают, что телефон выполнил операцию. Финальная проверка должна подтвердить именно результат на устройстве.

## Что важно знать

- Первый установочный профиль — Android ARM64 и native Termux.
- У каждого пользователя свои телефон, private repository, SSH-ключ и tunnel.
- Bridge выполняет только явно разрешённые встроенные операции; произвольные shell-команды не поддерживаются.
- Android может останавливать фоновые процессы; 24/7 не гарантируется.
- Бесплатный tunnl.gg имеет ограничения по трафику, простою и длительности сессии.
- Для полноценной связи ChatGPT нужен канал, способный записывать запросы и читать результаты. GitHub connector может быть read-only.
- Это независимый open-source проект, не официальный продукт OpenAI и не одобрен OpenAI.
